# Schoolroom Frontend

React + Vite + Ant Design / TypeScript

ใช้ Node.js 24.x, รัน `npm ci`, คัดลอก `.env.example` เป็น `.env` และตั้ง `VITE_API_URL` เป็น URL Backend ที่ลงท้าย `/api`

- พัฒนา: `npm run dev`
- Build: `npm run build`
- Vercel: Root Directory `frontend`, Framework `Vite`, Output Directory `dist`
- ตั้ง `VITE_API_URL` ก่อน build และอนุญาต origin ของเว็บนี้ใน `FRONTEND_ORIGIN` ของ Backend

คู่มือรวมและขั้นตอนส่งงานอยู่ที่ `../README.md`
